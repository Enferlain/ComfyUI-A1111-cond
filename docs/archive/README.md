snapshots, not current feature guarantees or active task lists. Use the root
README for supported behavior and Beads for current work.

- `AUTOCOMPLETE_PLAN.md`: original phased implementation proposal.
- `USAGE_ISSUES_FINDINGS.md`: usage investigation and candidate fixes. Some issues

were moved here.
